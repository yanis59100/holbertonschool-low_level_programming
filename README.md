# Holberton School Low-Level Programming Projects

This repository contains the low-level programming projects I completed during my studies at Holberton School.  
The focus of these projects was to develop a strong understanding of C programming, algorithms, memory management, and system-level concepts.

## Projects Overview
- C programming exercises  
- Pointers, arrays, and strings  
- Memory management and dynamic allocation  
- Implementation of algorithms and data structures  
- Basic understanding of operating system concepts  

## Tech / Stack
- C programming language  
- Linux environment  
- Git for version control  

## What I Learned
- Writing efficient C code  
- Understanding memory management and pointers  
- Building and using data structures  
- Implementing algorithms from scratch  
- Debugging and compiling code in Linux  

## Usage
Clone the repository and explore individual project folders to see source code, instructions, and examples.
